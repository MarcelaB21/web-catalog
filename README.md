# Vertex Atelier

Vertex Atelier es un catálogo web desarrollado con Next.js, orientado a la exhibición y solicitud de figuras 3D personalizadas mediante una experiencia visual moderna e intuitiva.

El proyecto organiza productos por categorías y facilita el contacto directo con clientes a través de WhatsApp.

---

## Problema resuelto

Este software fue desarrollado para mejorar la presencia digital del negocio y facilitar la visualización de productos disponibles.

La solución permite presentar figuras 3D de forma organizada, mejorar la experiencia de navegación y simplificar las solicitudes de compra mediante contacto directo por WhatsApp.

Con ello, se fortalece la visibilidad comercial del negocio y se optimiza la atención a clientes potenciales.

---

## Funcionalidades

- Catálogo organizado por categorías
- Diseño moderno y responsive
- Navegación rápida e intuitiva
- Integración directa con WhatsApp
- Presentación visual optimizada de productos
- Escalable para futuras categorías y módulos
